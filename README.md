# VGC Service Control

Мини-утилита для Windows: показывает статус службы `vgc` и процесса `vgtray`, умеет запускать и то, и другое.

## Использование

1. Скопируйте `VgcStatus.exe` на другой ПК (больше ничего не нужно).
2. Запустите двойным щелчком, подтвердите запрос UAC (программа всегда работает от администратора — без этого службу не запустить).
3. Статус обновляется сам каждые 2 секунды. Кнопка **«Запустить»** активна, только когда служба остановлена.

Имя службы можно переопределить параметром:

```
VgcStatus.exe ИмяДругойСлужбы
```

## Требования

- Windows 10/11 (или любая Windows с .NET Framework 4.x — он встроен).
- Сама служба `vgc` должна быть установлена (ставится вместе с Vanguard).

## Что показывает

Окно разделено на две области: слева служба **vgc**, справа процесс **vgtray**.

vgc (служба):

| Статус | Значение |
|---|---|
| РАБОТАЕТ (зелёный) | служба запущена |
| ОСТАНОВЛЕНА (красный) | служба остановлена, кнопка «Запустить» активна |
| ЗАПУСКАЕТСЯ / ОСТАНОВКА (жёлтый) | переходное состояние |
| НЕ НАЙДЕНА (серый) | служба не установлена на этом ПК |

vgtray (процесс, проверяется через список процессов Windows):

| Статус | Значение |
|---|---|
| РАБОТАЕТ (зелёный) | трей Vanguard запущен |
| НЕ ЗАПУЩЕН (красный) | процесса нет, кнопка «Запустить vgtray» активна |
| НЕ НАЙДЕН (серый) | нет `C:\Program Files\Riot Vanguard\vgtray.exe` |

Кнопка **«Запустить vgtray»** запускает `vgtray.exe` из каталога Vanguard
(рабочая папка — этот же каталог) и через 3 секунды перепроверяет статусы.
Пока процесс уже работает, кнопка неактивна.

## Язык интерфейса

В правом верхнем углу — переключатель языка. Он показывает тот язык, на который переключит:

- интерфейс на русском → надпись **Language** (клик → английский);
- интерфейс на английском → надпись **Язык** (клик → русский).

Переводится всё: окно, статусы, кнопки, сообщения об ошибках и диагностический отчёт
(отчёт формируется на языке, выбранном в момент открытия).

## Диагностика («Почему не запускается?»)

Кнопка внизу окна открывает подробный отчёт, а при неудачном запуске он открывается сам:

- тип запуска (`Start=3` вручную, `Start=4` отключена);
- путь к файлу службы и проверка, существует ли он;
- учётная запись службы и зависимости (с их состоянием);
- коды выхода Win32 / службы и PID;
- последние ошибки и предупреждения из журнала `System` за 24 часа, где упоминается `vgc` или `vgk`;
- отдельный блок по процессу `vgtray`: путь к файлу и запущен ли он (PID);
- отдельный блок по драйверу `vgk`: состояние, тип запуска, наличие `vgk.sys`, код выхода;
- блок «Вероятная причина» с конкретными выводами и командой исправления.

Отчёт можно скопировать одной кнопкой.

Если служба отключена (тип запуска «Отключена»), программа покажет подсказку с командой:

```
sc config vgc start= demand
```
